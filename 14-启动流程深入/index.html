14.2 UEFI vs Legacy BIOS

对比Legacy BIOSUEFI
启动方式MBR (446B 引导代码)EFI System Partition (FAT32)

EFI Stub — 不需要 GRUB 也能启动

现代 Linux 内核内嵌 "EFI stub"，本身就是一个 EFI 应用，可被 UEFI 固件直接执行：

# 把 vmlinuz 复制到 ESP，UEFI 启动菜单加一条即可，无需 GRUB
# 前提：先确认 ESP 目录存在
mkdir -p /boot/efi/EFI/Linux/
cp /boot/vmlinuz /boot/efi/EFI/Linux/
efibootmgr -c -d /dev/nvme0n1 -p 1 -L "Linux" -l "/EFI/Linux/vmlinuz" \\
    -u "root=/dev/nvme0n1p2 ro initrd=\\EFI\\Linux\\initrd"

14.3 GRUB 2 的多阶段启动

# GRUB 分多阶段是因为 MBR 只有 446 字节, 装不下完整代码

Stage 1:  MBR (446 B) → 加载 stage 1.5
Stage 1.5: 紧跟 MBR 的扇区 → 包含 fs 驱动 (能读 ext4 等)
Stage 2:  从 /boot/grub/ 加载完整 GRUB 代码 + grub.cfg
        → 显示启动菜单 → 加载 kernel + initramfs → boot

14.4 initramfs — 为什么需要

"鸡生蛋"问题

内核需要根文件系统（如 ext4 on LVM on /dev/nvme0n1p2）才能跑用户程序， 但挂载根文件系统需要先加载 LVM、文件系统、磁盘驱动，而这些是用户态 mkfs/lvm 命令配合的。 解决：把这些工具打包成一个最小镜像 initramfs，内核先用它，准备好后再切换到真根。

# 查看你的 initramfs
lsinitramfs /boot/initrd.img-$(uname -r) | head

# 解包看
mkdir /tmp/initrd && cd /tmp/initrd
zcat /boot/initrd.img-$(uname -r) | cpio -idmv

14.5 start_kernel() 初始化顺序

/* init/main.c — 简化版执行顺序 */
asmlinkage __visible void __init start_kernel(void) {
    set_task_stack_end_magic(&init_task);
    smp_setup_processor_id();
    boot_cpu_init();             // 标记 CPU 0 上线

    page_address_init();         // 页地址映射
    early_security_init();
    setup_arch(&command_line);   // 架构相关初始化
    setup_command_line(command_line);
    setup_per_cpu_areas();
    smp_prepare_boot_cpu();

    build_all_zonelists(NULL);
    page_alloc_init();
    pr_notice("Kernel command line: %s\n", saved_command_line);

    setup_log_buf(0);
    vfs_caches_init_early();     // dcache/icache
    sort_main_extable();
    trap_init();                 // 设置 IDT
    mm_init();                   // ★ 内存管理

    sched_init();                // ★ 调度器
    preempt_disable();
    local_irq_disable();
    radix_tree_init();
    
    early_irq_init();
    init_IRQ();                  // 中断子系统
    tick_init();
    rcu_init();
    init_timers();
    hrtimers_init();

    local_irq_enable();          // ★ 终于开中断

    console_init();              // 现在能 printk 到屏幕

    proc_root_init();
    cgroup_init();
    fork_init();
    proc_caches_init();
    buffer_init();
    security_init();
    vfs_caches_init();           // ★ VFS 完整初始化
    signals_init();

    rest_init();                 // 创建 pid 1 后变 idle
}

14.7 systemd — 现代 init

systemd 取代了传统 SysV init / Upstart，特点：

  • 并行启动：服务依赖图，无依赖的服务并发起
  • 按需 (socket-activation)：服务先不起，端口连接时再起
  • cgroup 直接集成：每个 service 自动一个 cgroup
  • 统一日志 journald：结构化日志
systemctl status                # 当前 target
systemctl list-dependencies     # 依赖树
systemd-analyze blame           # 启动时间贡献排序
systemd-analyze critical-chain  # 关键路径
journalctl -b -p err            # 本次启动错误日志
