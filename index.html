🐧 Linux 内核学习指南

一份系统性的、从入门到专家级的 Linux 内核学习路径。 以 Linux 0.11（仅 14000 行）为切入点理解全貌，以 Linux 2.6 / 5.x / 6.x 对照现代演进。 每章包含：核心机制讲解、源码逐行解析、SVG 架构图、可动手实验。

为什么这样学

现代 Linux 内核已超过 3000 万行代码，直接读完不现实。 本指南遵循"小内核入门 → 现代内核拓展 → 专家级专题"的路径：

  1. Linux 0.11：14k 行包含 OS 全部核心概念，可完整读完
  2. Linux 2.6.0：现代框架成型，VFS/kobject/RCU 全部就位
  3. Linux 5.x/6.x：CFS、eBPF、io_uring、容器、KVM 等专题深入

🗺️ 内核架构全景

用户空间 → 系统调用 → 内核子系统 → 驱动 → 硬件

📖 配套书单

  • 《Linux 内核完全注释》
    赵炯
    入门首选 · 配合 Linux 0.11 源码逐行注释，中文资料中无可替代
  • 《深入理解 Linux 内核》(Understanding the Linux Kernel)
    Daniel P. Bovet & Marco Cesati
    进阶必读 · 基于 2.6 内核全面拆解，是中级开发者的"圣经"
  • 《Linux 设备驱动程序》(Linux Device Drivers, 3rd ed)
    Jonathan Corbet, Alessandro Rubini, Greg Kroah-Hartman
    驱动开发权威 · 官方电子版免费 (LWN)
  • 《Linux 内核设计与实现》(Linux Kernel Development)
    Robert Love
    综合理解 · 文笔流畅，覆盖广，适合通读
  • 《深入 Linux 内核架构》(Professional Linux Kernel Architecture)
    Wolfgang Mauerer
    深度参考 · 1000+ 页详尽剖析，作字典用
  • 《BPF Performance Tools》
    Brendan Gregg
    现代可观测性 · 学完 12 章后必读
  • 《操作系统：精髓与设计原理》
    William Stallings
    理论基础 · 没有 OS 背景请先读此
